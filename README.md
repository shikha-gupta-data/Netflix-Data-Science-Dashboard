
# Netflix Data Science Dashboard

An interactive Netflix data analysis dashboard built using Python and Streamlit.

## Project Overview
This project analyzes Netflix movies and TV shows to understand content distribution, release trends, and popular genres.

## Features
- Total Movies and TV Shows
- Content Type Distribution
- Year-wise Content Growth Trend
- Top 10 Genres
- Interactive Dataset Preview
- Download Filtered Dataset

## Technologies Used
- Python
- Pandas
- Plotly
- Streamlit

## Project Files
- app.py
- requirements.txt
- Dataset.csv

## How to Run
Install the required libraries:

pip install -r requirements.txt

Run the dashboard:

streamlit run app.py

## Dataset
Netflix titles dataset in CSV format.
